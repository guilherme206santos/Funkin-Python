# Créditos dos assets do Friday Night Funkin'

Arquivos copiados do repositório **FunkinCrew/funkin.assets** para uso **educacional** (trabalho de faculdade):

| Arquivo                         | Origem                                | Uso no jogo                         |
|---------------------------------|---------------------------------------|-------------------------------------|
| `notes.png` / `notes.xml`       | `shared/images/notes`                 | setas que descem (notas)            |
| `noteStrumline.png` / `.xml`    | `shared/images/noteStrumline`         | receptores (parado, apertado, acerto) |
| `NOTE_hold_assets.png`          | `shared/images/NOTE_hold_assets`      | corpo e ponta das notas longas      |
| `fonte_bold.png` / `.xml`       | `preload/images/fonts/bold`           | letras dos títulos e menus          |
| `../../fonts/texto.ttf`         | `fonts/vcr.ttf` (VCR OSD Mono)        | textos de menus, HUD e pontuação    |

Esses arquivos **não** estão sob a licença MIT do código do projeto: consulte o `LICENSE.md` do repositório
original antes de qualquer outro uso (publicação, redistribuição ou uso comercial).
