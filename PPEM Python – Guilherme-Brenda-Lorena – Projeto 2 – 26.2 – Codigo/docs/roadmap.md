# Roadmap

| Sprint | Entrega | Critério de aceitação |
|--------|---------|-----------------------|
| 01 | Janela Pygame, laço a 60 FPS, 8 receptores desenhados | Janela abre e fecha pelo X; setas aparecem nas posições corretas |
| 02 | Relógio em ms, chart, notas rolando | Notas chegam ao receptor no tempo do chart (BPM 120) |
| 03 | Teclado, `julgar()`, combo e pontos | SICK/GOOD/BAD/SHIT corretos; erro zera o combo |
| 04 | Vida, personagens, pausa, voz que silencia, recorde | Pausa congela o tempo; recorde persiste entre execuções |
| 05 | Testes unitários e executável | `python -m unittest discover tests` passa; `.exe` roda sem Python |
| 06 | Menus, 4 músicas, 3 dificuldades, opções (teclas, FPS, tela cheia) | Ver `docs/sprints/sprint-06.md` |
| 07 | Calibração de áudio, notas longas, downscroll, prática, resultados, efeitos | Ver `docs/sprints/sprint-07.md` |
| 08 | Visual do FNF, resolução real, introdução, música de menu, multijogador | Ver `docs/sprints/sprint-08.md` |
| 09 | Modo personalizado: importar música do jogador e gerar as setas | Ver `docs/sprints/sprint-09.md` |

## Ideias extras
Charts feitos à mão, diálogos e modo história, sprites animados, suporte a controle (gamepad), editor de charts para ajustar as setas geradas, separar voz e instrumental, leitura de charts no formato do FNF.
